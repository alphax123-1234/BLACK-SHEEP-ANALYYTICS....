# 🐑 BLACK SHEEP - Uganda Social Listening System

A production-ready social listening platform designed for the Ugandan market, featuring localized NLP for Kampala street slang, Luganda code-switching, interactive Uganda map visualization, and real-time sentiment analysis.

## 🌟 Features

- **🗺️ Interactive Uganda Map**: Real-time sentiment visualization with color-coded regions
- **😊 Multi-Mood Detection**: Detects 6 emotional states (Happy, Excited, Neutral, Frustrated, Angry, Sad)
- **🌤️ Weather Integration**: Real-time weather data for each location
- **📊 Advanced Visualizations**: Mood distribution, brand sentiment, and location analytics
- **💾 Dual-Storage**: Cloud (Neon.tech) with automatic local CSV fallback
- **🛡️ Compliance Ready**: Built with Uganda's Data Protection Act compliance
- **💰 Zero Budget**: 100% free-tier cloud resources and open-source tools
